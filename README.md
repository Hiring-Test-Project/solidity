# Settle a payment (Solidity)

Implement `settle` in `src/SumAmounts.sol`. Plan on 15 minutes. The rules are in [SPEC.md](SPEC.md).

Do not change `test/SumAmounts.t.sol`.

From this directory:

```bash
forge test
```

This directory is only the Solidity task. Create a branch and push it. Do not change `test/`, `SPEC.md`, or `.github/`.

From this directory:

```bash
git checkout -b candidate/<your-name>
git add src/SumAmounts.sol
git commit -m "Implement settlement"
git push -u origin candidate/<your-name>
```
